# Chimera 128D + P2P Portfolio Integration

The Java/Koronos track exposes the 128D semantic state model over its processor, kernel, service and trusted-node research abstractions.

The authenticated P2P boundary supports capability negotiation, request/response, publish, snapshots, deltas and acknowledgements. Peer identity, sequence/replay state, payload hashes and optional signatures are validated before state is accepted.

Trusted federation remains opt-in and local-policy controlled. The protocol excludes unsolicited scanning, credential/private-key exchange, arbitrary executable transfer and remote command execution.

Java, C++, Node.js and Python interoperability is defined through deterministic JSON/JSONL schemas and conformance vectors.
